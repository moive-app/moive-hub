# MOIVE Knowledge Hub

MOIVE 팀의 기획, 디자인, 개발, 운영 정책, 의사결정 기록을 한곳에서 관리하는 지식 허브입니다.
이 저장소의 문서는 팀이 합의한 기준을 남기고, 변경 이력을 검토 가능하게 하며, 사람이든 AI든 같은 최신 맥락에서 질문에 답할 수 있도록 돕습니다.

## 시작하기

- 저장소 운영 규칙은 [AGENTS.md](AGENTS.md)에서 확인합니다.
- 문서의 공통 용어와 작성 템플릿은 `docs/_meta/`에서 관리합니다.
- 화면별 디자인·기획·개발·QA 진행 현황은 [docs/design/screens.md](docs/design/screens.md)에서 확인합니다.
- 중요한 팀 결정은 `docs/decisions/`에 기록합니다.

## 문서 구조

```text
docs/
├── _meta/          # 용어, 문서 작성 규칙, 책임자, 공통 템플릿
├── product/        # 비전, 로드맵, 요구사항, 지표
├── design/         # 디자인 원칙, 화면 관리, 디자인 시스템, UX 리서치
├── engineering/    # 아키텍처, 개발 표준, 운영 절차, 기술 결정
├── policy/         # 개인정보, 보안, 콘텐츠·운영 정책
├── decisions/      # 팀 차원의 의사결정 기록
├── meetings/       # 회의록과 액션 아이템
└── archive/        # 더 이상 유효하지 않은 보존 문서
```

## 운영 원칙

1. Discord Forum/Thread는 기능별 질문·의견·논의·결정 과정의 원본입니다. 미확정 의견은 공식 기준으로 취급하지 않습니다.
2. 중요한 문서에는 상태, 담당자, 마지막 검토일, 원본 링크를 기록합니다.
3. 문서를 변경할 때는 관련 의사결정·화면 관리표·외부 원본 링크도 함께 확인합니다.
4. 더 이상 유효하지 않은 문서는 삭제보다 `deprecated` 또는 `archived` 상태와 대체 문서를 남깁니다.
5. 비밀정보, 개인식별정보, 접근 토큰, 고객 원문 데이터는 저장하지 않습니다.

## 원본 시스템과의 연결

| 시스템 | 원본으로 관리하는 정보 | Hub에서의 역할 |
| --- | --- | --- |
| Discord Forum/Thread | 기능별 질문, 의견, 논의, 결정 과정 | 논의 맥락과 결정 근거를 연결 |
| Notion | 최종 확정된 상세 기획 및 정책 | 공식 문서를 연결하고 핵심 내용을 찾기 쉽게 정리 |
| Figma | 디자인 | 화면별 원본 링크와 진행 상태를 관리 |
| GitHub | 구현 및 개발 이력 | 이슈·PR 등 실행 근거를 연결 |
| MOIVE Hub | 승인된 핵심 지식과 원본 간 연결 | 팀과 AI가 최신 맥락을 검색·참조하는 인덱스 |

Discord와 Notion, Figma, GitHub의 원본 링크는 관련 Hub 문서에 함께 남깁니다. 특히 Discord의 의견은 Notion 공식 문서 또는 승인된 의사결정 기록으로 확정되기 전까지 사실·정책·요구사항으로 인용하지 않습니다.
