# 의사결정 기록

이 폴더는 여러 직군에 영향을 주거나 되돌리기 어려운 MOIVE 팀의 확정 결정을 기록합니다.
Discord Forum/Thread는 결정에 이르는 논의 과정의 원본이고, Notion은 최종 확정된 상세 기획·정책의 공식 문서입니다. 결정 기록은 이 두 원본과 핵심 결론을 연결해 검색하기 쉽게 정리합니다.

## 기록 규칙

- 확정되지 않은 Discord 의견만으로는 `approved` 결정 기록을 만들지 않습니다.
- Discord에서 논의가 있었다면 Forum Channel과 관련 Thread 링크를 구분해 기록합니다.
- 최종 상세 기획 또는 정책이 있다면 Notion 공식 문서 링크를 함께 기록합니다.
- 새 기록은 [결정 템플릿](templates/decision.md)을 바탕으로 `YYYY-MM-DD-주제.md` 형식으로 작성합니다.
